Connect YouTube (optional)

Automatic sync needs your own Google Cloud OAuth Client ID. This app does not send your credentials to us; sync runs in your browser. For production use, configure OAuth consent, add your app's origin as an authorized JavaScript origin, and enable YouTube Data API v3 plus YouTube Analytics API. YouTube Analytics does not expose every Studio metric; “Stayed to watch” should be entered manually if it is not returned for your account.

Backup and restore

Your tracker data is saved on this device/browser. Export backups regularly, especially before clearing browser data.

How this app works

  • Manual planning, stats, notes, and learnings work offline after the app is loaded.
  • Automatic YouTube sync requires internet, Google OAuth configuration, and API quota.
  • Data is stored locally in this browser. It does not automatically sync across devices.
  • For multi-device cloud backup or Play Store distribution, a backend and release signing are separate steps.
